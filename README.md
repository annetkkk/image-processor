# Image Processor

Учебный C++ проект: консольное приложение для обработки BMP-изображений.

Программа читает BMP-файл, применяет к нему последовательность фильтров из командной строки и сохраняет результат в новый BMP-файл.

## Что реализовано

- чтение и запись BMP-изображений;
- парсинг аргументов командной строки;
- последовательное применение нескольких фильтров;
- обработка ошибок при некорректных аргументах;
- базовая архитектура с отдельными модулями для BMP, парсинга аргументов, фильтров и pipeline.

## Поддерживаемые фильтры

- -crop width height — обрезка изображения;
- -neg — негатив;
- -gs — оттенки серого;
- -sharp — повышение резкости;
- -edge threshold — выделение границ;
- -blur sigma — размытие;
- -vignette intensity radius — виньетка.

```bash
./image_processor input.bmp output.bmp -crop 800 600 -gs -blur 0.5
