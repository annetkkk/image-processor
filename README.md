# Image Processor

Учебный C++ проект: консольное приложение для обработки BMP-изображений.

Программа читает BMP-файл, применяет к нему один или несколько фильтров из командной строки и сохраняет результат в новый BMP-файл.

## Что реализовано

- чтение и запись 24-bit BMP-изображений;
- парсинг аргументов командной строки;
- последовательное применение нескольких фильтров через pipeline;
- обработка некорректных аргументов и ошибок при работе с файлами;
- разделение проекта на модули: BMP, аргументы, фильтры, pipeline;
- дополнительный собственный фильтр vignette.

## Поддерживаемые фильтры

- -crop width height — обрезка изображения;
- -neg — негатив;
- -gs — оттенки серого;
- -sharp — повышение резкости;
- -edge threshold — выделение границ;
- -blur sigma — размытие;
- -vignette intensity radius — виньетка, затемнение краёв изображения.

Фильтр vignette был добавлен самостоятельно как дополнительное расширение стандартного набора фильтров.

## Пример запуска

```bash
./image_processor input.bmp output.bmp -crop 800 600 -gs -blur 0.5

В этом примере программа:

1. читает input.bmp;
2. обрезает изображение до 800×600;
3. переводит его в оттенки серого;
4. применяет размытие;
5. сохраняет результат в output.bmp.
