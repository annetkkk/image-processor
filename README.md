# Image Processor

Учебный C++ проект: консольное приложение для обработки BMP-изображений.

Программа читает BMP-файл, применяет к нему последовательность фильтров из командной строки и сохраняет результат в новый файл.

---

## Что реализовано

- чтение и запись 24-bit BMP;
- парсинг аргументов командной строки;
- последовательное применение фильтров (pipeline);
- обработка ошибок и некорректного ввода;
- модульная структура проекта;
- дополнительный фильтр vignette.

---

## Поддерживаемые фильтры

- -crop width height — обрезка изображения  
- -neg — негатив  
- -gs — оттенки серого  
- -sharp — повышение резкости  
- -edge threshold — выделение границ  
- -blur sigma — размытие  
- -vignette intensity radius — затемнение краёв изображения  

Фильтр vignette реализован самостоятельно как дополнительное расширение.
